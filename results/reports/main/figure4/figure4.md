# Figure 4

Global parameter trajectories and site-wise objective-function changes are shown on the same optimization iteration axis.
Black traces show reporting-scale parameter changes from the final estimate, and colored traces show site-wise objective-function changes from the final site contribution.
All y-axis values use signed log10 transformation, sign(x) * log10(1 + abs(x)), to keep large transient movements visible without compressing the rest of the trajectory.
